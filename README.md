# 合欢魔女 · 养成录（Demo）

修仙题材 · 女性向文字养成游戏 demo。合欢宗第七峰，满门皆是女弟子——友情与爱情并重，宗主身上藏着一条完整的长篇主线。

## 运行

直接用浏览器打开 [index.html](./index.html) 即可，无需安装任何东西。存档自动保存在浏览器本地（localStorage）。

## 内容规模（当前版本）

- **宗主长篇主线**：六卷 77 场完整剧情（正文约 1.5 万字，含选项与每场反馈全文约 2 万字可读量）。
- **七位角色个人线**：每人已写 **十卷共 106–114 场完整剧情**，含个人线正文、对话话题、专属事件、邀约与随机闲聊，**每人累计可读内容均超过 2 万字**（实测 20,000–20,114 字/人）。十卷分别写：初识定情 → 风浪成长 → 立足守成 → 大冲突 → 大婚成家 → 传位归隐 → 江湖风云 → 新生传承 → 回响 → 终章，通过人物界面的「个人线」按钮推进。
- **随机对话**：49 句随机闲聊（每人 7 句，随好感解锁），每次「交谈」都会随机带出一句，不再是一成不变的开场。
- **随机邀约**：每人 4 套邀约文案（21 组新变体 + 原版），地点和台词随机轮换，重复邀约也有新鲜感。
- **地点剧情**：13 个地点 × 各 100–102 个专属事件 = **1312 个**（含第三至十八批长篇互动事件，场景描写每地约 520–590 字），事件+描写每地累计 **10,130–11,298 字**可读量，**13 个地点全部达到万字目标**（实测全部通过）。各地新增「探索」动作，可主动触发当地事件。
- **对话话题**：9 个角色共 60 个话题，随好感逐级解锁。
- **见闻录**：**40 条**世界观词条（上古秘辛 / 宗门旧事 / 宗门秘辛 / 正魔风云 / 红尘百态），在剧情、地点事件与藏经阁「翻阅典籍」中解锁。

## 地图系统（踩地图）

右侧是**世界地图**，点击地点即可移动：

- 同一地域内移动不耗时；**跨地域（合欢宗 ⇄ 云梦城 ⇄ 外域）移动耗一月**。
- 每个地点都有**详细描述**，进入时写进记事，并常驻显示在地图下方。
- 地图下方是**此地之人**——该地点能找到的 NPC，点击即可展开互动。
- **行动按钮按地点过滤**：只显示当前地点能做的事。
- 每个地点 **100+ 个专属事件**（随机与条件触发），在对应地点行动、探索或跨地域赶路时随机触发；事件含选择分支、好感/属性增减与见闻录解锁。
- 部分地点有专属行动：温泉小憩、翻阅典籍（解锁见闻）、采药、切磋、论剑、血祭、逛市集。

## 宗主长篇主线（剧透提示）

到**主殿**找到宗主月华，好感超过 50 后「主线」按钮解锁。六卷推进：卷一「月下」→ 卷二「暗流」→ 卷三「窥秘」→ 卷四「情劫」→ 卷五「真身」→ 卷六「共主」，含三个结局分支与终章回响。

## 玩法

### 修行循环

- 每项行动耗一月：修炼、修习媚术、下山采补、历练、闭关、购丹/服丹、歇息，以及各地点的专属行动。
- **境界**：凡人 → 炼气 → 筑基 → 金丹 → 元婴 → 化神（化神通关）。
- **媚术**：独立成长线（1–10 层）。
- **四维**：魅力 / 体质 / 心境 / 魔性。

### 好感与攻略

好感五阶：初识 → 相识 → 交心 → 情愫 → 定情。交谈（含随机对话与话题）、赠礼、邀约（随机文案）、个人线都能增进好感；好感 50 / 100 / 120 各解锁一段专属事件，120 为亲密剧情。

### 姐妹友情事件

与绯羽、惊鸿、温言的「闺中情谊」越深，越容易触发群体友情事件：姐妹夜话、花灯节同游、后山温泉、月下结义、生辰惊喜。

## 结局

- 化神通关：**魔尊临世**（走完宗主线另有彩蛋文案）。
- 败局：香消玉殒（体质归零）、心魔噬魂（心境归零）、以身饲魔（魔性满值）。
